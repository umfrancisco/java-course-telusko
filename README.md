# Master Java, Spring and Spring Boot, Spring Security, Spring AI, Docker and Microservices with Telusko (Udemy Course)

A collection of exercises, examples, and projects developed while following a Udemy course on **Java, Spring Framework, and Spring Boot**.

This repository documents my hands-on learning journey through the Java ecosystem, covering core programming concepts, backend development, REST APIs, database integration, application security, and modern development practices.

## Topics Covered

The course explores the following technologies and concepts:

- **Java:** Core Java, object-oriented programming (OOP), and fundamental programming concepts.
- **Maven:** Dependency management and project builds.
- **JDBC:** Database connectivity and SQL integration.
- **Spring Core:** Inversion of Control (IoC) and Dependency Injection (DI).
- **Spring MVC:** Web application development and the MVC architecture.
- **Spring AOP:** Aspect-oriented programming and cross-cutting concerns.
- **Spring Boot:** Application configuration, development, and deployment.
- **Spring REST:** RESTful API development and web services.
- **Spring Data JPA:** Database persistence and ORM.
- **Spring Security:** Authentication and authorization.
- **Spring AI:** Integration of generative AI capabilities into Java applications.
- **Docker:** Containerization and custom Dockerfiles.
- **Microservices:** Introduction to distributed application architecture.

## Learning Objectives

Through the exercises and projects in this repository, I aim to:

- Strengthen my understanding of Java and object-oriented programming.
- Learn how the Spring ecosystem simplifies backend development.
- Build REST APIs and integrate applications with relational databases.
- Understand dependency injection, persistence, and application security.
- Explore AI integration with Spring AI.
- Practice containerization and learn the fundamentals of microservices.
- Improve my ability to design, develop, and maintain backend applications.
